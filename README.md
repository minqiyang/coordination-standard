# Standards

Two peer coordination standards. Load exactly one per coordinator session.

```text
coordination-standard/               Coordination Standard 9.0: any coordinator agent
claude-herdr-coordination-standard/  Claude-herdr Coordination Standard 0.1: Claude Code coordinator in Herdr
project-notes/efr/, project-notes/zoe/  project handoffs and coordinator notes (local, not in git)
archive/                             historical drafts; do not load (local, not in git)
```

| Coordinator | Live policy files | How to start |
|---|---|---|
| Claude Code in a Herdr Tab | `claude-herdr-coordination-standard/coordinator.md`, `model_bindings.json` | [`claude-herdr-coordination-standard/README.md`](claude-herdr-coordination-standard/README.md) |
| Any other agent | `coordination-standard/coordinator.md`, `routing_table.json`, `model_bindings.json` | [`coordination-standard/README.md`](coordination-standard/README.md) |

Project notes are project-specific and are not part of either standard.
