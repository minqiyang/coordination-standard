# Agent instructions

Live coordinator policy, for a coordinator agent in a Herdr Tab: `claude-herdr-coordination-standard/coordinator.md` and `claude-herdr-coordination-standard/model_bindings.json`. The coordinator can be any agent CLI that can run background tasks, as the card says.

The earlier Coordination Standard 0.13.0 is kept on the git branch `coordination-standard-0.13` and is no longer maintained. Load it only when the owner asks for it by name.

Do not read, cite as current, or take gates from `archive/`. Those files are historical drafts with no authority.
