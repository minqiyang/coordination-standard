# Agent instructions

Live coordinator policy: `claude-rex-coordination-standard/coordinator.md`, `claude-rex-coordination-standard/model_bindings.json`, and the script `claude-rex-coordination-standard/bin/rex_agent.sh`. Workers run in Rex Tabs. The coordinator can be any agent CLI that can run background tasks, as the card says.

The Herdr card is kept in `claude-herdr-coordination-standard/`. Load it only when the owner asks for the Herdr card by name.

The earlier Coordination Standard 0.13.0 is kept on the git branch `coordination-standard-0.13` and is no longer maintained. Load it only when the owner asks for it by name.

Do not read, cite as current, or take gates from `archive/`. Those files are historical drafts with no authority.
